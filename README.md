# 🐍 Applied Python for Data Science & Scientific Computing

> *"Code is read much more often than it is written."* — Guido van Rossum

This repository documents my rigorous journey from core Python fundamentals to advanced data manipulation, algorithmic problem-solving, and scientific computing. 
Rather than just learning syntax, this portfolio focuses on **data wrangling, vectorization, object-oriented architecture, and clean code practices (PEP 8)** to prepare for real-world Data Science and Big Data Engineering challenges.

## 🎯 Objective
To build a robust, production-ready foundation in algorithmic thinking and data architecture, bridging the gap between raw data extraction and actionable scientific insights.

---

## 🛠️ Tech Stack & Ecosystem
* **Core Python:** Control Flow, Functions, OOP (Encapsulation, Inheritance, Polymorphism), Generators, Iterators.
* **Data Analysis & Manipulation:** `pandas` (DataFrames, Time Series, Aggregations), `NumPy` (Vectorization, Linear Algebra, Masking).
* **Data Visualization:** `matplotlib` (2D/3D plotting, custom layouts).
* **Scientific Computing:** `scipy` (Differential equations, optimizations).
* **Data Parsing & Extraction:** `re` (Regular Expressions), XML/CSV/TSV handling, Bioinformatics formats (FASTA, GenBank, PDB).
* **Environment:** `JupyterLab`, `Miniconda`.

---

## 🚀 Key Milestones & Projects

### 1. Advanced Data Parsing & Automation 🧬
* **GenBank to FASTA Converter:** Built a robust parser using **Regular Expressions (Regex)** to extract genomic features and convert complex biological data formats.
* **Proteome Word Search:** Engineered a script to search for specific patterns across the entire human proteome, optimizing dictionary lookups and string matching for large datasets.

### 2. Scientific Computing & Vectorization 📐
* **3D Center of Mass Calculation:** Used **NumPy** boolean masking and vectorized operations to calculate the center of mass of lipid membrane monolayers (bypassing slow Python `for` loops).
* **Pendulum Simulation (ODE):** Solved differential equations using the semi-implicit Euler method (`scipy`/`numpy`) and built an interactive **Tkinter GUI** to visualize the physics in real-time.

### 3. Data Wrangling & Analysis 📊
* **Kinase Protein Database Analysis:** Leveraged **Pandas** to clean, group, and analyze a 1,400+ row dataset of protein kinases. Performed time-series resampling and statistical aggregations (`groupby`, `pivot_table`).
* **Interactive Data Exploration:** Utilized **Jupyter Notebooks** with Markdown and `matplotlib` to create reproducible analytical reports.

### 4. Software Engineering & Clean Code 🏗️
* **Object-Oriented Programming (OOP):** Designed modular, reusable classes (e.g., `Molecule`, `Atom`, `Pendulum`) utilizing `@property` decorators for data encapsulation and validation.
* **Best Practices:** Strict adherence to **PEP 8**, comprehensive `docstrings` (NumPy style), modular script design (`if __name__ == "__main__":`), and exception handling (`try/except`).
